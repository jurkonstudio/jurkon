Ngeunaan Jurkon

Jurnal Koneksi (Jurkon) nyaéta média sosial minimalis, tempat nulis catetan ringkes sareng nyambung jeung batur tanpa kaributan nu kaleuleuwihi.

Nu dicekel ku kami

  • Ringkes jeung écés. Catetan pangpanjangna 250 karakter, pesen pangpanjangna 750 karakter.
  • Genah jeung aman. Aya pamariksaan tulisan, watesan spam, laporan, sareng blokir.
  • Tanpa iklan. Kami henteu ngajual data anjeun sareng henteu maké palacak iklan.
  • Anjeun nu nyekel kandali. Unduh data atawa hapus akun iraha waé.

Cara gawéna

Jurkon dijieun maké HTML, CSS, jeung JavaScript biasa, maké Supabase pikeun basis data sareng autentikasi, sarta di-hosting di GitHub Pages. Anjeun tiasa masangna dina layar utama ponsel siga aplikasi.
