Bab Jurkon

Jurnal Koneksi (Jurkon) iku media sosial minimalis, papan kanggo nulis cathetan cekak lan nyambung karo wong liya tanpa rame sing kabèh.

Sing dicekel

  • Cekak lan cetha. Cathetan paling akèh 250 aksara, pesen paling akèh 750 aksara.
  • Kepenak lan aman. Ana pamriksan tulisan, watesan spam, laporan, lan blokir.
  • Tanpa iklan. Kita ora ngedol dhata sampeyan lan ora nganggo pelacak iklan.
  • Sampeyan sing nyekel kendali. Unduh dhata utawa busak akun kapan waé.

Cara kerjané

Jurkon digawé nganggo HTML, CSS, lan JavaScript biasa, nganggo Supabase kanggo basis dhata lan autentikasi, lan dihosting ing GitHub Pages. Sampeyan bisa masang ing layar utama ponsel kaya aplikasi.
