关于 Jurkon

Jurnal Koneksi（Jurkon）是一款极简社交应用，让你写下简短的笔记，并与他人建立联系，没有多余的喧嚣。

我们的理念

  • 简短清晰。笔记最多 250 字符，私信最多 750 字符。
  • 舒适安全。提供内容检查、垃圾信息限制、举报和屏蔽功能。
  • 没有广告。我们不出售你的数据，也不使用广告追踪器。
  • 由你掌控。随时可以下载数据或删除账号。

运作方式

Jurkon 使用普通的 HTML、CSS 和 JavaScript 构建，以 Supabase 作为数据库和身份验证服务，托管在 GitHub Pages 上。你可以像应用一样把它添加到手机主屏幕。
